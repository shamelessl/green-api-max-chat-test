# Текстовый чат MAX на GREEN-API

Локальный прототип на React и Node.js для MAX через GREEN-API. Он проверяет состояние инстанса, отправляет текст и получает входящие уведомления через HTTP API. GREEN-API использует единый формат `waInstance` для MAX, WhatsApp и Telegram.

## Запуск для разработки

Нужен Node.js 20.19+ или 22.12+.

В первой консоли из этой папки:

```powershell
npm install
npm run server
```

Во второй консоли из этой же папки:

```powershell
npm run dev
```

Если порт `4179` занят, выбери свободный порт для сервера и передай его Vite-прокси. Например, в PowerShell первой консоли выполни `$env:PORT='4180'; npm run server`, а во второй `$env:API_SERVER_PORT='4180'; npm run dev`.

Открой `http://127.0.0.1:5173`. Введи `idInstance` и `apiTokenInstance` своего GREEN-API-инстанса, затем номер получателя с кодом страны и сообщение. GREEN-API выдаёт `apiUrl`, `idInstance` и `apiTokenInstance` в кабинете; перед запуском укажи адрес кабинета в `GREEN_API_BASE`, если он отличается от стандартного. Токен принимается сервером только в памяти процесса и не сохраняется в браузере или файлах проекта.

## Проверки и production-сборка

```powershell
npm test
npm run lint
npm run build
npm start
```

После сборки `npm start` раздаёт интерфейс и API на `http://127.0.0.1:4179`.

Если кабинет выдал отдельный API-хост, задай его перед запуском сервера: `$env:GREEN_API_BASE='https://<хост из кабинета>'; npm start`.

Для получения входящих сообщений в настройках инстанса GREEN-API должен быть включён HTTP API и отключён webhook URL, чтобы уведомления оставались в очереди ReceiveNotification. Приложение читает уведомление, сохраняет текст в оперативной памяти, затем подтверждает его через DeleteNotification.

## Границы прототипа

- Поддерживаются текстовые сообщения и один активный номер чата.
- Для отправки номера используется совместимый формат `номер@c.us`.
- Сообщения и учётные данные хранятся в памяти процесса; после перезапуска история очищается.
- Проверки используют локальный имитатор GREEN-API. Для реальной отправки и получения нужны собственные данные инстанса; в репозитории они отсутствуют.
- Для production нужны HTTPS, аутентификация пользователя и постоянное хранилище. Текущая сборка предназначена для локальной демонстрации одного пользователя.
